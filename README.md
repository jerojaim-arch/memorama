# Memorama (PWA)

Juego de memorama hecho con HTML, CSS y JavaScript, configurado como **Aplicación Web Progresiva (PWA)**: se puede instalar en computadora o celular y funciona sin conexión.

**Jugar:** https://jerojaim-arch.github.io/memorama/

## Archivos

| Archivo | Función |
|---|---|
| `index.html` | Estructura de la página |
| `style.css` | Diseño del tablero y las cartas |
| `app.js` | Lógica del juego, registro del service worker e instalación |
| `manifest.json` | Datos para instalar la app (nombre, íconos, colores) |
| `service-worker.js` | Caché de archivos para usar la app sin internet |
| `icon-192.png`, `icon-512.png` | Íconos de la app |
